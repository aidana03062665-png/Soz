СӨЗLAB — «Зерде» ғылыми жобасына арналған электронды сөздік және интерактивті ойындар.

Іске қосу: index.html файлын браузерде ашыңыз. Интернет қажет емес.

GitHub Pages: index.html файлын репозиторийдің негізгі бумасына жүктеп, Settings → Pages → Deploy from a branch → main / (root) таңдаңыз.

Бөлімдер: Басты бет, Сөздік (20 сөз), Ойындар (10 сұрақтық тест, сәйкестендіру, жады карталары), Зертхана (бағалау, балама ұсыну, CSV экспорт).

Маңызды: деректер тек браузердің localStorage қоймасында сақталады. Бірнеше құрылғыдағы нәтижелер автоматты түрде бірікпейді; ғылыми жұмыста пайдалану үшін CSV экспортын жасаңыз.

Терминдер қолданушы ұсынған құжаттан алынған және бекітілген ресми баламалар ретінде көрсетілмейді.
